# Рекомендательная система новостного сайта

Итоговая версия курсового проекта: подбор новостей по текущему запросу и истории
запросов пользователя.
Можно получить выдачу по запросу, учесть прошлые интересы или открыть персональную
ленту без нового запроса.

В корпусе 43 950 статей Lenta.ru за 2018 год. Для сравнения реализованы TF-IDF
и предобученная модель `intfloat/multilingual-e5-small` без дообучения.
Интерфейс работает на Streamlit.

## Установка

Проект проверен на macOS с Python 3.9.6 и ускорением PyTorch MPS.
Команды ниже выполняются из корня проекта. Если окружение ещё не создано:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip check
```

## Запуск готового архива

Архив для сдачи содержит подготовленный корпус в `data/processed/`,
представления новостей в `models/` и E5 в `models/hf_cache/`.
Скачивать датасет и пересчитывать представления не требуется.

После установки зависимостей запустите интерфейс:

```bash
.venv/bin/python -m streamlit run src/app.py
```

Откройте адрес из терминала, обычно `http://localhost:8501`.
Если Streamlit просит email, оставьте поле пустым и нажмите Enter.
Первое обращение к E5 занимает больше времени: модель загружается в память.

Для проверки работы с локальной моделью без обращения к Hugging Face:

```bash
HF_HUB_OFFLINE=1 .venv/bin/python -m streamlit run src/app.py
```

Данные также можно скачать тут:
[Lenta.ru News Dataset](https://github.com/yutkin/Lenta.Ru-News-Dataset)

```

При первой подготовке E5 скачивается из интернета. Скрипты сохраняют корпус
и представления в тех же каталогах, которые используются готовым архивом.
После этого интерфейс запускается командой выше.

## Как пользоваться

Введите текущий запрос и выберите метод. Для персонализации добавьте прошлые
запросы в боковой панели, по одному на строку, нажмите «Применить историю»
и включите «Учитывать историю запросов». Профиль строится по последним пяти
непустым запросам.

Режим «Персональная лента» использует только историю. Чтобы сравнить выдачи
при одинаковых условиях, отключите добавление текущего запроса в историю.
История хранится в пользовательской сессии.

## Эксперименты и документация

Для пересчёта метрик по сохранённым выдачам и ручным оценкам:

```bash
.venv/bin/python -u src/evaluate_final.py
```

Для этого корпус и модель не нужны. Оценены 315 пар «сценарий — статья»
из 56 выдач: 12 сценариев с текущим запросом и четыре персональные ленты.

- [Основные результаты](results/evaluation/evaluation_report.md) — качество рекомендаций.
- [Быстродействие](results/performance_report.md) — время обращений к системе.
- [Дополнительное сравнение](results/additional_comparison/report.md) — собственный поиск E5 и библиотечная функция `semantic_search`.
- [Условия дополнительного сравнения](docs/additional_comparison_protocol.md).
- [Содержимое results](results/README.md) — назначение файлов экспериментов.

Система работает с архивом, а не с обновляемой новостной лентой. Сценарии заданы
вручную и размечены одним оценщиком; результаты относятся к этому эксперименту.
